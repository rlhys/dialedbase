## How to Maintain & Improve SEO

### 1. Page Titles & Meta Descriptions
- Keep titles under 60 characters
- Meta descriptions should be 150-160 characters
- Include primary keywords naturally

### 2. Open Graph Images
- Use 1200x630px images for best display
- Compress images under 200KB
- Test with: https://www.opengraph.xyz/

### 3. Structured Data
- JSON-LD schemas are implemented in index.html
- Update organization schema if company info changes
- Test with: https://schema.org/validator/

### 4. Sitemap & Robots
- Sitemap: /sitemap.xml (already created)
- Robots.txt: /robots.txt (configured)
- Update these when adding new pages

### 5. Internal Linking
- Link between Home → About → Work pages
- Use descriptive anchor text
- Keep internal link structure logical

### 6. Mobile Optimization
- Site is mobile-first responsive
- Test with Google Mobile-Friendly Test
- Core Web Vitals should be optimized

### 7. Performance
- Images are lazy-loaded
- CSS/JS are minified on build
- Use Vercel's built-in performance monitoring

### 8. Search Console & Analytics
- Submit sitemap to Google Search Console
- Monitor Core Web Vitals
- Track keyword rankings
- Monitor crawl errors

### 9. Content Strategy
- Update work/portfolio regularly
- Blog or case studies would help SEO
- Keep content fresh and relevant

### 10. Link Building
- Get backlinks from industry publications
- Partner with complementary agencies
- Mention in case studies/testimonials
